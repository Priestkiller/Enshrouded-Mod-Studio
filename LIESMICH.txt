ENSHROUDED MOD STUDIO 0.4.10 — OEFFENTLICHES STUDIO-PAKET

Windows x64 mit .NET Framework 4.8. ZIP vollständig entpacken.

Von 0.4.9: ZIP manuell in einen neuen Ordner entpacken, neue Anwendung starten
und „Altes Setup übernehmen“ mit dem bisherigen vollständigen Studioordner.
Der alte Ordner bleibt erhalten. Details: README.md und UPDATES.txt.

Ab 0.4.10 können spätere Tool-Updates nach Bestätigung automatisch übernommen
werden. Profile, Data und vorhandene geprüfte private Runtime bleiben erhalten.
Das Tool-Update wendet kein Profil an und ändert keine Spielarchive.

Die ursprüngliche Patcher-/Parser-Runtime liegt diesem öffentlichen ZIP nicht
bei. Sie wird aus einer vorhandenen vollständigen Installation übernommen und
anhand der erwarteten Hashes geprüft. Ohne sie ist noch kein Spielpatch möglich.
Keine Weitergabe- oder Lizenzberechtigung für Fremdkomponenten wird behauptet.

44 Optionen; bestehende Einstellungen bleiben erhalten. Für Zähmung und
andere Einzelwirkungen gelten die sichtbaren Prüfhinweise; Datenbelege sind
keine Bestätigung im laufenden Spiel. Details: EINSTELLUNGEN.txt.
