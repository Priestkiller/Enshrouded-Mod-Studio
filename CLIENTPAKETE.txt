CLIENTPAKETE AB MOD STUDIO 0.4.25

1. STUDIO PATCHT
Den von Manager 0.15.28 verwalteten Enshrouded-Server-Installationsordner
wählen. Spiel und Server schließen, Optionen einstellen und Patch anwenden /
aktualisieren. Speichern allein wendet keine Spieländerungen an.

2. MANAGER ÜBERNIMMT
Studio erkennt die Managerbindung im Installationsordner. Es baut passende
Clientänderungen aus einer bereits lokal vorhandenen, getrennten
Clientinstallation desselben Spielbuilds. Der Manager übernimmt und prüft die
lokale Übergabe automatisch. Danach den Server mit den neuen Daten neu starten.

3. SPIELER SYNCHRONISIEREN
Im Spielerclient 0.16.13 Synchronisieren & Spielen wählen. Passende Änderungen
werden geladen und geprüft; der bisherige Modstand wird vor dem Einbau gesichert.

VORHANDENE LOKALE BASIS
Eine gültige bisherige Clientbasis-Einstellung hat Vorrang. Fehlt sie, sucht
Studio in seinen Profilen und Steam-Bibliotheken des angemeldeten Benutzers.
Keine oder mehrere passende Installationen: den gemeldeten Grund prüfen und
unter Werkzeuge > Clientpaket für Servermanager die passende vorhandene
Clientbasis auswählen. Auf einem reinen Server ohne Clientinstallation kann
Studio kein passendes Clientpaket erzeugen. Es gibt keinen Upload von
Spieldateien eines Mitspielers und keinen Ersatz durch Serverarchive.

ÜBERGABE UND AUFBEWAHRUNG
Die feste Managerablage liegt unter .ugsm-studio-transfer im verwalteten
Installationsordner. Sie enthält Clientpakete, einen Status und minimale
gehashte Prüfnachweise. Es werden keine privaten Profile oder Desktoprechte
an den Manager weitergegeben. Aktuelle und vorherige eigene Pakete sowie
zwei eigene Prüfnachweise bleiben erhalten. Unbekannte Daten bleiben geschützt.

Die bisherige manuelle Einrichtung bleibt für nicht vom Manager verwaltete
Installationen verfügbar. Ein passendes vorhandenes Paket wird nach erneuter
Prüfung wiederverwendet. Ein Tool-Update wendet das Profil nicht aufs Spiel an.

Dateiprüfungen bestätigen den vorbereiteten Modstand. Sie versprechen keine
bislang ungeprüfte Spielwirkung einer einzelnen Option.
